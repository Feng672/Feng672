## Academic Projects
### GalactaTec
Space Invaders-style arcade game built in Python, featuring enemy flight patterns, match configuration, a persistent hall of fame with top scores, and first-place rewards.

### ISA Digital Signature
Custom Instruction Set Architecture (ISA) designed to perform digital signatures on documents, including a secure vault for storing and protecting private keys and initialization vectors.

### Robot MCU
Assistant robot capable of transporting small objects, controlled through a web application connected to an ESP32 microcontroller for remote movement control.

### LogoTec
Custom compiler capable of generating object code that drives a physical drawing mechanism, translating compiled instructions into real-time drawing actions on custom-built hardware.

### Scheduling Ships
C-based simulation representing multithreaded process scheduling through ships navigating a channel, with a physical LED display mirroring the on-screen simulation.

### Distributed Audio Analysis System with Physical Visualizer
Distributed system built in C that securely processes audio across a 3-node cluster connected via SSH and OpenMPI, aggregating and displaying results on a master node.
